# Manual Testing Portfolio 🧪

Manual testing documentation for my self-developed e-commerce website — [Myntra Clone](https://github.com/Shreya-88/Myntra-Clone-Website) — covering test case design, execution, and defect reporting.

## 🎯 Objective
To apply manual testing concepts (test case design, UI testing, responsive testing, and bug reporting) on a real web project and document the complete testing process.

## 📂 Repository Contents
| File | Description |
|------|-------------|
| `Myntra-Clone-Test-Cases.md` | 18 manual test cases covering UI, navigation, links, and responsiveness |
| `Bug-Report.md` | Defect reports with steps to reproduce, severity, and status |

## 🛠️ Testing Concepts Applied
- Test Case Design (positive & negative scenarios)
- UI / Layout Testing
- Cross-Browser Testing (Chrome, Edge)
- Responsive Testing (Desktop, Tablet, Mobile viewports)
- Link & Navigation Verification
- Defect Reporting & Severity Classification
